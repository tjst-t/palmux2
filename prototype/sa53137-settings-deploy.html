アプリ設定 デプロイ設定
⟳ 未適用の変更に 再起動が必要なもの が含まれます（addr, sso_secret）。下部の Apply で systemctl --user restart palmux2 が実行されます。

サーバ/公開設定のマスター（~/.config/palmux/config.toml）。install.sh のパラメータと同じ source-of-truth を編集します。即時 要再起動 要特権 のバッジで反映コストを示します。

[server]
待受アドレス 要再起動server.addr
ベースパス 要再起動server.base_path
tmux prefix 要再起動server.tmux_prefix
WS 最大接続 / Workspace 要再起動server.max_connections
0 = 無制限
Caddy admin API 即時server.caddy_admin
claude バイナリ 即時server.claude_bin
[public] · 公開 / 認証
公開ドメイン 要特権public.domainTLS 証明書 + Caddy の書換が要るため特権操作
この変更は root を要します。Apply で palmux reconcile-system の確認に進みます（or install.sh 再実行）。
BasicAuth ユーザ 要再起動public.basic_auth_user
秘密（マスク表示・書込のみ）
SSO 署名鍵 要再起動secrets.env · PALMUX_SSO_SECRET変更すると全セッションが無効化されます
設定済み ••••••••
ログインパスワード 要再起動secrets.env · BASIC_AUTH_HASH (bcrypt)
設定済み
bcrypt は palmux 内で計算。平文は保存しません。
Cloudflare API トークン 要特権secrets · CLOUDFLARE_API_TOKEN公開ドメインの wildcard TLS (DNS-01) に使用
設定済み
Caddy が DNS-01 challenge で *.<domain> 証明書を発行する際に使用。変更は Caddy 再起動（特権）を伴います。Zone DNS 編集権限のトークン。
Apply は差分を 即時 / 再起動 / 特権 に分類し、必要なものだけ実行します。
