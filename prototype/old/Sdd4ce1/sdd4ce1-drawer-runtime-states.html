Drawer · runtime indication (Sdd4ce1-5-4, revised)

Drawer rows are unchanged from current production. No per-row runtime icon — that felt cluttered with 4+ Workspaces visible at once. Runtime is surfaced in 3 less intrusive places instead.

1. Header chip — the chip next to the breadcrumb shows the runtime of the active Workspace ( lxd-container · ready ). Text-only — no invented icon. Always visible, no extra clicks. The state dot color follows the existing semantic palette: ● ready / ● starting / ● failed.

2. Right-click row — context menu shows current runtime + "Change runtime…" submenu (separate prototype).

3. Non-ready badges — starting spinner / failed tag appear on the right of the row only when state ≠ ready, plus a glance footer with progress / error + retry. Ready rows show nothing — Drawer keeps its original look.
