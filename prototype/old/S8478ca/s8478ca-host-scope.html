This is the repo-independent Host scope (host--0000) — a bash-only terminal for gh auth login / claude login.

It is not a Workspace and has no runtime — so it shows the ⌂ Host label, never a runtime-selector or runtime-chip. Distinct from a Workspace whose runtime.kind = host.
