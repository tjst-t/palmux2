After（S67cb0e-4: Markdown 描画）

Sprint S1f75ec-2 で『タブバー単一化 + branch.claude_mode』を実装したが、実態は backend に『claudeagent N 個 + claudetui 1 個』が並存し、frontend が claudetui を非表示にして claudeagent の中身を claudetui で描画するという構造的に脆い設計だった。結果として:

  • 1 branch に 2 つの Claude タブがあっても全部同じ daemon を共有（= タブ単位 mode は実現不能）
  • バッジは最初のタブだけに表示、他タブが何 mode か区別できない
  • ⌘K で切り替えると同 branch の全タブが連動（= 意図しない巻き込み）

5 stories

  1. -1 claudetui を per-tab daemon 化（Multiple=true）
  2. -2 claudeagent + claudetui を統一 claude Provider に統合
  3. -3 repos.json schema 変更 + tab-scope API 新設
