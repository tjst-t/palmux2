Workspace feature-x is open.

Switching runtime restarts this Workspace's tabs: the current host tmux session is replaced by a fresh container session.

  • Claude resumes via claude --resume (auth & history are shared via ~/.claude).
  • Running shell processes in Bash tabs are terminated.
  • Anything installed on the host stays; the new container starts clean.
