Right-click a file → the new Download item streams the file to the browser as an attachment (GET …/files/download?path=…). Full size — no preview truncation, binaries included.

Download uses a native <a download> navigation (cookie auth rides along), so it goes through the browser's own download manager — no in-app progress bar, no JS buffering of the file.
