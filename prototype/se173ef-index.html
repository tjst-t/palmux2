3 つの情報設計案。タブ（下線リンク）をクリックすると各コンテンツのモックが開きます（コンテンツは 3 案で共有、違いはタブ集合＝ナビゲーション IA）。 現状は Overview / Sprint Detail / Dependencies / Decisions / Refine（Refine は常に空）。

A: アクション志向（5 タブ）推奨

「今、自分が見るべきもの」を Review に集約する行動起点の構成。Dependencies は Overview 内にグラフとして畳み、Refine は削除。

Overview Sprint Detail Review Milestones Decisions
+ Review（needs_user_review / blocked / high compromises / overlooked / reopen を横断集約 → autopilot review 導線）
+ Milestones（comprehension + compromises）　△ Dependencies → Overview に内包　− Refine 削除

B: 保守的（5 タブ）

既存の構造を極力保ち、空の Refine を Milestones に置き換えるだけ。Dependencies は単独タブのまま。Review 集約は作らない。

Overview Sprint Detail Dependencies Decisions Milestones
+ Milestones　− Refine 削除　既存タブ維持（Review 集約なし、要対応は Overview の軽い roll-up のみ）

C: 網羅（7 タブ）

情報量最大。Review・Milestones・Backlog を全て独立タブに。Dependencies も単独維持。タブは多いが全部に到達しやすい。

Overview Sprint Detail Review Milestones Decisions Dependencies Backlog
+ Review + Milestones + Backlog（47 件の backlog も可視化）　− Refine 削除　Dependencies 単独維持
