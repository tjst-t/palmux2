Sdd4ce1 · Phase A — WorkspaceRuntime selector & Drawer indication REVISED · ROUND 2

Drawer rows look identical to current production (no runtime icon prefix). Active Workspace's runtime is shown via a text-only header chip (lxd-container · ready). Non-ready rows show inline starting / failed tags only.

Sdd4ce1-5-4

 FILES
Multi-select · tinted bg + action bar

Cmd/Ctrl-click toggles, Shift-click range. No checkboxes — selected rows get the accent-tinted bg + 2px accent left border (Finder/VSCode style). Touch: long-press to enter select mode. Action bar: Move… / Delete / Cancel.

 FILES
Inline new-file row

Click 📄＋ → placeholder row with file icon at the bottom of the list, focused input ready for the name. Enter to create, Esc to cancel.

 FILES
Inline new-folder row

Same pattern, folder icon, trailing slash hint. Subpaths allowed (foo/bar creates the chain).

 FILES
Inline rename

F2 / Rename… replaces the row in place with an editable input pre-selected on the basename. Same row, same position. Single-item only.

 FILES
Delete confirm · batch

Modal lists each item being deleted (path · size · last modified). Recursive directory deletes are flagged. Single-item case shrinks to one block.

 FILES
Move modal · batch + completion

Target = a directory (basenames preserved for batch). Repo-root-relative input with ⌘K-@-style directory completion. Per-item FROM→TO preview.
